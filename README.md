# SyntroSend Homebrew Tap

Official Homebrew Tap for **SyntroSend** on macOS.

> **Fast P2P file transfer and secure SyntroCloud storage alternative to AirDrop.**

SyntroSend allows you to instantly send files, folders, and clipboard text directly between Windows, macOS, Linux, and Android devices with high-speed local P2P transfer and zero-knowledge encrypted SyntroCloud storage.

---

## Installation

To install SyntroSend via Homebrew, run:

```bash
brew tap syntrosend/tap
brew install syntrosend
```

Or in a single command:

```bash
brew install syntrosend/tap/syntrosend
```

---

## Upgrade

To update to the latest version of SyntroSend:

```bash
brew update
brew upgrade syntrosend
```

---

## Uninstall

To uninstall and clean up all application support caches:

```bash
brew uninstall --zap syntrosend
```
